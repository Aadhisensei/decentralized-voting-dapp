💡 The wallet address acts as a unique voter ID on the blockchain. Each address can vote only once.

📝 Step 2: Add Candidates

Contract Owner

The contract deployer can add candidates to the ballot. This calls the addCandidate() function on the smart contract, which stores the candidate name on-chain.

💡 Each "Add Candidate" action creates a blockchain transaction. It needs to be confirmed in MetaMask with a small gas fee (in test ETH).

🗳️ Step 3: Cast a Vote

0 total votes

Click "Cast Vote" on a preferred candidate. This calls the vote() function on the smart contract. The contract verifies the address hasn't voted before, then records the vote permanently on the blockchain.

These results are read directly from the blockchain using the getCandidate() function. Anyone can verify them on Sepolia Etherscan.

🔍 Contract Explorer — Read Functions

view / returns / memory

Call the smart contract's view functions directly. These are read-only calls that cost zero gas and return data stored on the blockchain.

function getCandidateCount() external view returns (uint256)
Returns the total number of candidates stored in the contract.
—
function getCandidate(uint256 _id) external view returns (uint256 id, string memory name, uint256 voteCount)
Returns the full details of a candidate. The string memory keyword means the name is loaded into temporary memory for the return value.
—
function hasVoted(address) external view returns (bool)
Checks the hasVoted mapping for a given wallet address. Returns true if that address has already voted, false otherwise.
—
function owner() public view returns (address)
Returns the wallet address that deployed this contract. Set once in the constructor() and can never be changed.
—
💡 All functions marked view are read-only — they don't modify blockchain state and cost zero gas. No MetaMask popup appears because no transaction is being sent. The data is fetched directly from a Sepolia node.

⚙️ What's Happening Under the Hood

📜

Smart Contract (Solidity)

The voting logic lives in a Solidity smart contract deployed on Ethereum. It stores candidates, tracks votes, and enforces one-vote-per-address.

🌐

Frontend (HTML/CSS/JS)

This web page connects to the blockchain using ethers.js. It reads data from the contract and sends transactions when a vote is cast.

🦊

MetaMask Wallet

MetaMask signs transactions with the wallet's private key and broadcasts them to the Sepolia test network.

⛓️

Sepolia Testnet

A public Ethereum test network where we deploy and test our contract using free test ETH, without spending real money.

Built with Solidity, Ethers.js v6, and Hardhat on the Sepolia Testnet
